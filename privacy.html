Privacy Policy

Effective date: 26 November 2026

AI with GeniusSau Clipper ("the tool") is a personal automation tool operated by Saurav Patel. This policy explains what data the tool handles and how it is protected.

1. Data the tool accesses

  • Google account authorisation — an OAuth 2.0 refresh token for the Google account that owns the AI with GeniusSau YouTube channel, requested through Google's standard consent screen.
  • YouTube Data API data — the channel's basic profile, its uploaded-video list, and per-video view/like/comment counts. The tool also uploads new videos, thumbnails and playlists to that channel.
  • Video files and transcripts — source videos the operator chooses to process, plus locally generated clips, captions and thumbnails.

2. Where data is stored

Everything is stored locally on the operator's Mac. The OAuth token lives in ~/.config/clipper/ with file permissions restricted to the operator. Video files and transcripts live in the project folder. The tool does not operate any server and does not send this data to any third party.

3. How data is used

Data is used only to produce short clips and publish them to the authorised YouTube channel, and to display the channel's own performance statistics to the operator. It is never used for advertising, profiling, or resale.

4. Sharing

We do not sell, rent, trade or share Google user data with third parties. The only outbound transfers are the video/metadata uploads the operator explicitly requests through the YouTube Data API, and the video download requests to the platform hosting the source video.

5. Retention and deletion

The OAuth token is retained until revoked. The operator can revoke access at any time at myaccount.google.com/permissions, and can delete all local files by removing the project folder. Locally stored data is deleted on request by emailing the address below.

6. Google API Services User Data Policy

AI with GeniusSau Clipper's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Security

Access tokens are stored with owner-only file permissions. The tool runs on a single operator-controlled machine and is not exposed to the public internet.

8. Children

The tool is not directed to children under 13 and does not knowingly collect data from them.

9. Changes

Material changes to this policy will be posted on this page with a new effective date.

10. Contact

Questions or deletion requests: saurav123patel@gmail.com
